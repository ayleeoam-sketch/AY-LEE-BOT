# 🎬 Clips — drop your recordings here

Record your screen clips, name them in order, and upload them to this folder.
Once they're on GitHub, the finished video (voiceover + subtitles) comes back here.

## Step-by-step

1. Record with your phone's screen recorder (silent is fine — voiceover gets added later).
2. Rename clips in order:

| File | Step |
|------|------|
| `01_github_star_fork.mp4` | Open GitHub → ⭐ Star → Fork |
| `02_session_id.mp4` | Session site → pairing code → copy session ID |
| `03_link_device.mp4` | WhatsApp → Linked devices → link + type code |
| `04_render_deploy.mp4` | Render deploy → paste `SESSION_ID` + `OWNER_NUMBER` |
| `05_bot_alive.mp4` | WhatsApp → bot replies to `.menu` |

3. Upload to GitHub: **Add file → Upload files** → drop clips here → commit.
4. Say "done" — the finished video is built and pushed back.

## Size tips

- GitHub web upload caps each file at **25 MB**. Record at **720p** — a few minutes is fine.
- Clip bigger than 25 MB? Split it into `_part1` / `_part2`, or ask to enable Git LFS.
- Common formats are fine: `.mp4`, `.mov`, `.mkv`.

> ⚠️ Never upload your real `SESSION_ID` or `.env` here — keep those private.
